FIBA Mobile · 설치 방법

[0] 서버 준비 (한 번만)
 1. Supabase 대시보드(픽셀 후프스 때 쓰던 프로젝트) → SQL Editor → New query
 2. fiba_mobile_setup.sql 내용을 전부 붙여 넣고 Run
 3. FIBA Mobile 전용 표(fm_로 시작)가 새로 생겨요. 픽셀 후프스 데이터와 완전히 따로예요.

[1] GitHub Pages에 올리기
 1. github.com → 오른쪽 위 + → New repository → 이름 fiba-mobile, Public → Create
 2. "uploading an existing file" → 이 폴더 안의 파일 전부와 bgm 폴더를 끌어다 놓기
 3. Commit changes
 4. Settings → Pages → Branch: main, 폴더 / (root) → Save
 5. 1~2분 뒤 주소: https://b40730771-max.github.io/fiba-mobile/

[2] 계정
 - 완전히 새 게임이라 모두 회원가입부터 새로 해요
 - 관리자(woonn)는 회원가입 말고 "로그인"으로, 픽셀 후프스 때 쓰던 비밀번호 그대로 들어가요
 - 다른 사람은 woonn 이름으로 가입할 수 없어요

[3] 폰·패드에 설치
 - 아이폰/아이패드: Safari → 공유 → 홈 화면에 추가
 - 안드로이드: Chrome → ⋮ → 앱 설치
