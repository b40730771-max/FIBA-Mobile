FIBA Mobile · 통합 서버 버전

[0] Supabase 준비 (한 번만)
 1. Supabase 대시보드 → SQL Editor → 받은 SQL 붙여 넣고 Run
 2. Authentication → Sign In / Providers → Email → "Confirm email" 끄기 → Save

[1] GitHub Pages에 올리기
 1. github.com → 오른쪽 위 + → New repository → 이름 pixel-hoops, Public → Create
 2. "uploading an existing file" → 이 폴더 안의 모든 파일과 bgm 폴더를 통째로 끌어다 놓기
 3. Commit changes
 4. Settings → Pages → Branch: main, 폴더 / (root) → Save
 5. 1~2분 뒤 주소: https://내아이디.github.io/pixel-hoops/

[2] 폰·패드에 설치
 - 아이폰/아이패드: Safari → 공유 → 홈 화면에 추가
 - 안드로이드: Chrome → ⋮ → 앱 설치

[3] 계정
 - 처음 열면 로그인/회원가입 화면이 떠요. 구단 이름 + 비밀번호(6자 이상)
 - 구단 이름은 한 명만 쓸 수 있어요 (대소문자 구분 없음)
 - 진행 상황은 자동으로 서버에 저장되고, 다른 기기에서 로그인하면 그대로 이어져요
 - 비밀번호를 잊으면 찾을 수 없으니 꼭 기억해 두세요

[4] 기존 기록 옮기기
 - 같은 기기에서 하던 기록: 회원가입 후 "이 기기 기록으로 시작"
 - claude.ai·다른 기기 기록: 거기서 설정 → 내보내기 → 복사 → 가입 후 "저장 코드로 시작"에 붙여 넣기

[5] 친구
 - 친구 → 플레이어 검색 → 구단 이름 검색 → 덱 보기 / 친구 추가
 - 실시간 대전: 방 만들기 → 4자리 코드 공유

[6] 업데이트
 - 새 파일을 같은 저장소에 같은 이름으로 다시 올리면 돼요. 앱을 껐다 켜면 적용돼요.
